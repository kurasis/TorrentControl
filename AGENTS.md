# Repository instructions

## Web interface reviews

- When developing or changing the web interface, including `frontend/`, use
  [web-design-guidelines](.agents/skills/web-design-guidelines/SKILL.md) to review
  the result.
- For UI, UX, design, or accessibility audit requests, explicitly apply this
  skill and identify it in the response.
- Read the local `SKILL.md` and fetch the current rules from its guidelines URL
  before each review. If fetching fails, report the limitation and the domains
  that need access; do not claim that the current guidelines were checked.
- Apply the guidelines within the application's Win32/WebView2 architecture and
  existing security requirements. See [architecture](docs/architecture.md) and
  [building and testing](docs/building.md) for project context and validation.
